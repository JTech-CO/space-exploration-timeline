# Space Exploration Timeline

인류의 우주 연구·발견·탐사 역사를 아래에서 위로 읽는 3개 언어 시각화 웹입니다. 맨 아래의 고대 천문학에서 출발해 과학 혁명, 로켓 시대, 달 탐사와 최근의 우주 임무까지 올라갑니다.

[라이브 사이트](https://jtech-co.github.io/space-exploration-timeline/) · [English README](README.md)

## 주요 기능

- 모든 사건에 번역된 제목·설명, 관련 시각 객체, 출처 링크를 함께 배치합니다. 같은 해의 여러 사건도 각각의 항목으로 읽을 수 있습니다.
- Three.js로 만든 보이저, 웹 우주망원경, 스푸트니크, 탐사선과 천체를 제공합니다. 활성화된 객체를 드래그해 회전하고 버튼으로 확대·축소하거나 시점을 초기화합니다. 터치 화면에서는 두 손가락으로 회전하고 한 손가락으로 연표를 스크롤합니다. 초점이 있는 객체는 방향키로 회전, `+` / `-`로 확대·축소, `Home`으로 초기화할 수 있습니다. WebGL을 사용할 수 없어도 정적 일러스트는 표시됩니다.
- 페이지는 가장 오래된 사건이 있는 아래쪽에서 시작합니다. 시대 버튼과 연도 선택기로 긴 연표를 이동할 수 있고, 영어·한국어·일본어 전환 시 읽던 사건의 위치를 유지합니다.
- 대기, 별, 지구의 가장자리와 함께 올라가는 연출을 제공합니다. 고도 표시기는 인류의 탐사 범위가 넓어지는 흐름을 표현한 비유이며, 각 발견의 실제 고도를 뜻하지 않습니다.
- 모바일 배치, 키보드로 조작할 수 있는 컨트롤, 동작 줄이기 설정을 지원합니다.

## 실행과 확인

현재 Vite 요구 사항에 맞는 Node.js 22.12 이상을 사용합니다.

```bash
npm install
npm run dev
npm run validate
npm run build
npm run preview
```

완전한 정적 사이트로, API 키·계정·백엔드·환경 변수가 필요하지 않습니다.

브라우저 검사는 Playwright와 Chromium이 설치된 환경에서 실행합니다. 프로덕션 미리보기를 먼저 켠 뒤 다른 터미널에서 검사합니다.

```bash
npm install --save-dev playwright
npx playwright install chromium
npm run preview -- --port 4280
# 다른 터미널에서 실행:
npm run test:e2e
```

다른 로컬 서버를 검사하려면 `E2E_URL`을 지정합니다. 브라우저 검사는 항목 수, 아래에서 위로 읽기, 번역과 사건 위치, 이동 기능, 모바일 가로 넘침, 객체 조작과 대체 표시를 확인합니다. `npm run validate`는 데이터 형식과 참조를 검사하며 역사적 주장의 진위나 외부 출처 페이지의 접속 가능성까지 독립적으로 확인하지는 않습니다.

## 프로젝트 구조

```text
src/
  main.js             페이지 구성, 언어·시대 이동, 배경 상태
  style.css           반응형 연표와 객체 스타일
  data/timeline.js    사건 데이터와 편집 기준 날짜
  i18n/ui.js          UI 번역과 고도 층 정의
  visuals/observatory.js  공유 Three.js 뷰어와 SVG 일러스트
scripts/
  validate.mjs        외부 의존성 없는 데이터 무결성 검사
  e2e.mjs             Playwright 브라우저 검사
public/               정적 자산
.github/workflows/    GitHub Pages 배포 워크플로
```

[`src/visuals/observatory.js`](src/visuals/observatory.js)가 객체를 렌더링합니다. 사건마다 가벼운 일러스트를 유지하고, 화면에 보이는 객체 사이에서 Three.js 캔버스 하나를 공유해 사건 수만큼 WebGL 컨텍스트를 만들지 않습니다. 필요할 때 화면을 갱신하며, 뷰어를 종료하면 렌더러와 모델 리소스를 해제합니다. 동작 줄이기 설정에서는 카메라의 관성 이동을 제거합니다. 객체 위에서 마우스 휠을 사용해도 연표 스크롤을 이어갈 수 있습니다.

## 콘텐츠 수정과 출처

`src/data/exhibits.js`는 사건의 고유 ID에 전용 객체를 연결합니다. 81개 사건에 72개 전용 장면을 제공하며, 번역된 설명에 도해의 의미와 한계를 표시합니다. `src/visuals/study-scenes.js`의 공통 기하 정보를 `study-renderer.js`가 Three.js와 SVG로 각각 그립니다. 같은 실제 탐사선이 등장하는 사건은 객체를 공유할 수 있지만, 서로 다른 개념과 장비는 형태를 구분합니다. 코페르니쿠스는 태양계를 유지하고, 케플러는 항성 하나와 예시 행성 두 개, 초점 중심의 타원 궤도, 같은 시간 동안의 면적, 시간 슬라이더를 제공합니다. 슬라이더는 WebGL 없이도 동작합니다.

`npm run test:exhibits`로 사건 연결·기하 정보·케플러 법칙을 검사합니다. 로컬 미리보기가 실행 중일 때 `npm run test:exhibits:browser`로 모든 객체의 렌더링, 슬라이더, 키보드 조작, 모바일 배치와 WebGL 대체 표시를 검사합니다. `E2E_URL`로 미리보기 주소를 지정할 수 있으며 이 검사의 기본 포트는 4281입니다.

[`src/data/timeline.js`](src/data/timeline.js)의 각 사건은 고유한 `id`, 역사적 `year`(기원전은 음수), `en` / `ko` / `ja`로 된 `title`과 `body`, `category`, 지원하는 `visual`, 설명형 라벨과 HTTPS 주소로 된 `sources`를 갖습니다. 정확한 `date`와 번역된 `detail`은 선택 항목입니다. 문장을 수정할 때 ID를 유지하면 연도 이동과 언어 전환에서도 같은 사건을 추적할 수 있습니다.

매년 표시되는 눈금은 `TICK_START`부터 시작하고, 그 이전의 사건은 개별 항목으로 표시합니다. 같은 연도에 여러 사건을 추가할 수 있습니다. `UPDATED_AT`은 실시간 뉴스 제공을 뜻하는 값이 아니라 편집 기준 날짜(2026-10-04)입니다.

출처는 가능한 경우 임무 수행 기관, 천문대, 과학 기관과 원 논문을 우선합니다. 최근 사건을 추가하거나 주장을 수정할 때는 발사·조우·관측·발표 날짜를 구분해 확인해야 합니다. 기존 역사 기록을 유지하며 내용을 보강했으므로, 이번 작업에서 모든 기존 문장을 새로 독립 검증했다고 주장하지 않습니다. 일부 개괄적인 출처는 항목의 모든 세부 내용에 대한 직접 증거가 아니라 배경 자료이며, 우선권 논쟁과 고대의 근사 연대도 고려해야 합니다.

객체는 교육을 위한 절차적 재구성입니다. 알아볼 수 있는 주요 장비와 부품을 표현하지만, 비행용 공학 모델·측량 지형·정확한 축척 모형·천체 항법 자료는 아닙니다. 같은 객체를 관련 사건에 재사용할 수 있으며, 당시의 정확한 장비 배치나 관측 기하를 재현한다고 보장하지 않습니다.

## 배포와 라이선스

Vite의 빌드 결과는 `dist/`에 생성됩니다. 기존 GitHub Actions 워크플로는 `main`에 푸시된 내용을 GitHub Pages에 배포하며, `base: './'`로 프로젝트 하위 경로를 지원합니다. 로컬 검사와 빌드만으로는 사이트를 배포하지 않습니다.
